# sanji.band

Static site and electronic press kit for SANJI. Hosted on GitHub Pages from
the `main` branch root. No framework; one JSON file is the source of truth
and a 100-line Node script renders the pages.

## Edit content

Everything written (bio, lineup, roles, festivals, stages shared, booking
contact, page titles and descriptions) lives in **`src/content.json`**.
Change it there, then:

```sh
npm install     # once
npm run build   # writes index.html, sanji-press-kit.html, 404.html, sitemap.xml
```

Commit the JSON *and* the rebuilt HTML together. If you forget, the
`Build site` GitHub Action rebuilds and commits for you on `main`, and fails
a pull request whose HTML is stale.

Never hand-edit the root HTML files. The next build overwrites them.

## Edit markup or styles

- `src/templates/` has one template per page (Mustache syntax).
- `src/partials/` has what both pages share: `<head>` metadata, base CSS
  tokens, the booking block, and analytics.

## Add or replace an image

1. Put the original in `src/images/` (festival logos, member portraits,
   backgrounds) or `assets/photos/band/` (full-res photos that are
   themselves the download).
2. Add a job to `scripts/images.js` if it is a new file.
3. `npm run images` writes the optimized web version into `assets/` and
   records its pixel size in `src/image-dims.json`, which the build uses for
   `width`/`height` attributes.
4. Reference the optimized path from `src/content.json`, then `npm run build`.

## Layout

```
src/content.json        single source of truth for all copy and data
src/templates/          index.html, press-kit.html, 404.html
src/partials/           head.html, base.css, booking.css, booking.html, analytics.html
src/images/             image originals (not served)
src/image-dims.json     generated by scripts/images.js
src/stage-plot-source.html  SVG source the stage plot PNG/PDF were exported from
scripts/images.js       image optimisation pipeline (sharp)
build.js                renders templates -> root HTML + sitemap.xml
assets/                 served files: optimized images, EPK PDFs, patterns
index.html, sanji-press-kit.html, 404.html, sitemap.xml   GENERATED
robots.txt, CNAME, favicon_ngoni.png
```
